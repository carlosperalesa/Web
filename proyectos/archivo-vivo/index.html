UN PROYECTO PERSONAL

La misma persona. Nuevas formas de construir.

Diseño e implementación técnica de las distintas versiones de este portafolio.

  • HTML, CSS y JavaScript
  • Interfaces e interacción
  • Organización de contenidos
  • Mejora continua
01

Primero, ordenar lo importante.

V1 reúne mi perfil, experiencia, proyectos y formación. El punto de partida fue dar estructura a la información y hacerla fácil de recorrer.

02

Después, explorar otras maneras de contar.

V2 incorpora tarjetas que se transforman, capas y movimiento. La misma información se convierte en una oportunidad para probar una navegación más visual.

03

Convertir la web en una experiencia.

V3 lleva el portafolio a un escritorio interactivo, con ventanas y accesos. En la versión actual vuelvo a priorizar la claridad, la accesibilidad y las historias detrás de cada proyecto.

04

Conservar lo aprendido.

Este archivo mantiene las versiones funcionales para poder explorar sus decisiones y diferencias. Evolucionar también implica revisar, simplificar y elegir qué vale la pena conservar.
